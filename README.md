## About The Project
<h3>Discover Suds&Buds: Your Ultimate Brewery Browser</h3>
Welcome to <b>Suds&Buds</b>, the ultimate destination for beer enthusiasts and casual drinkers alike. Suds&Buds is your one-stop browser website designed to explore, discover, and savor the world of breweries like never before.

Key Features:<br/>
Search Filters: Customize your search with our filters.

Interactive Maps:<br/>
Navigate the beer world with our interactive maps. Find breweries near you or plan a brewery tour in your favorite travel destination.

Detailed Brewery Profiles: Get in-depth information on each brewery.

Personalized Dashboard: Save your favorite breweries, track your beer tasting journey.

Join Suds&Buds today and embark on a flavorful journey through the diverse and exciting world of beer. Cheers to discovering your next great brew!

## Getting Started

### Prerequisites
* Java 17
* Maven

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/FrancescoDiGiovanni/common-lib.git
   ```
2. Open it in an IDE (ex. Intellij)
4. Open the main dir and run
    ```sh
   mvn clean install
   ```
